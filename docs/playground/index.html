Use the playground

  1. Edit the recorder options, then select Apply & restart.
  2. Interact with Form interactions or DOM changes.
  3. Select an event to inspect it, or open Raw JSON to copy the recording.
  4. Open Player and select Load latest events to replay it.

Applying settings or switching examples clears the captured events and player and starts a new recording. Recording continues during playback; load the latest events to include new interactions.

Every recorder option is listed from the start. Options at their rrweb default are greyed; edit any value in place, or delete an option's line to fall back to its default. // and /* */ comments are informational and ignored when settings are applied; the gutter's +/− buttons fold an option's contents onto one line. ignoreCSSAttributes accepts an array of strings. The playground supplies emit; callbacks, plugins, and regular expressions require JavaScript and cannot be configured here.
